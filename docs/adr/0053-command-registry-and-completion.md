# 53. One command registry drives help and completion in every client

Date: 2026-10-11
Status: Accepted

Slash commands were listed in four places: the service answered `/model` and
`/models`, the TUI parsed a dozen more, Telegram answered `/start`, `/help` and
`/new`, and each client wrote its own help line. Nothing knew the whole set, so
help drifted and no client could complete a command.

## Decision

- `internal/chat/registry.go` declares every slash command once as a
  `CommandSpec` (name, usage, summary, clients) with optional argument
  completers. Clients are `web`, `tui`, `telegram` and `wechat`; a command lists
  only the clients that execute it today.
- `GET /api/commands?client=NAME` returns a client's specs.
  `POST /api/commands/complete` takes `{client, conversationId, text}`, where
  `text` is the input up to the cursor, and returns suggestions that replace its
  last whitespace-separated token. Free text, multi-line input and finished
  arguments return `[]`. Arguments complete from live state: models
  (`/model`, `/model default`), conversations (`/open`), pending approvals
  (`/approve`, `/deny`) and fixed choices (`/test`, `/cloud`, …). Vendor model
  listings get two seconds, so typing never waits on a slow provider.
- Both UIs ask the service for completions and share one interaction: Tab
  accepts, ↑/↓ choose, Esc dismisses, and Enter accepts only when the suggestion
  changes a partly typed token, so a complete command still sends. Stale answers
  are dropped (a sequence number in the TUI, an effect flag in React).
- Telegram's `/help` is `chat.Help("telegram")`. The contract types
  (`CommandSpec`, `Suggestion`, `CompletionRequest`) are generated by
  `cmd/contracts`.

## Consequences

Adding or changing a command's usage happens once, in Go, and reaches help and
completion everywhere. Execution has not moved yet: TUI-only commands are still
parsed in `internal/tui`. The next steps are to run them through the registry with
structured results (Markdown, table, form, client action) so that the web UI and
channels gain them too, and to publish Telegram's command menu from the registry.
