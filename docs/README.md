# Mob documentation

These pages, with the repository's README and CONTRIBUTING, are published at
https://usemob.app/docs. Each level links to the next, so read only as deep as
you need:

1. [README](../README.md): what Mob is, install and first commands.
2. [Install](install.md): npm, Bun, nightly builds, archives and
   troubleshooting.
3. [Features](features/README.md): one page per part of Mob, grouped by what
   you want to do. Each page opens with how to use it and ends with how it
   works.
4. [Configuration keys](environment-variables.md): generated reference of file
   keys, CLI flags, `MOB_` variables, defaults and precedence.

For changing Mob:

- [Contributing](../CONTRIBUTING.md): setup, tests and pull request
  conventions.
- [Architecture](architecture.md): where code lives and the boundaries between
  packages.
- [Public site](website.md): how usemob.app is built and deployed.
- [UI style](ui-style.md), [Taking screenshots](screenshots.md),
  [Prompt evaluations](prompt-evals.md) and
  [Sandbox verification](sandbox-verification.md) for specific kinds of
  change.

Design discussion happens in issues and pull requests.
